🧩 Set up the Chrome Extension

One-time setup. The Chrome Extensions page has already been opened for you.

1
Go to the Chrome Extensions page (it opened automatically). If it did not, type chrome://extensions in the address bar and press Enter.
2
Turn on the Developer mode switch in the top-right corner of the page.
3
Click Load unpacked on the left.
4
A folder window opens. Click its address bar at the top, press Ctrl + V (the path is already copied), press Enter, then click Select Folder.

5
Click the puzzle icon (🧩) in Chrome and pin 📌 TezDM Integration.
