  2. Open Settings → Developer options and turn on USB debugging.
  3. Connect the cable, choose File transfer, then tap Allow on the phone.

2What to recover

3Save to

You will get

  • All photos & videos (DCIM, Pictures, Movies)

  • Music, recordings & downloads
  • Deleted files still in the trash, with names

1Connect your Android phone

USB debugging must be on (see Android page).

Not checked yetClick “Detect phone”.

2Save to

Copies Databases, Backups and Media. Rooted phones: key file too.

Where is my key?

  1. WhatsApp → Settings → Chats → Chat backup
  2. End-to-end encrypted backup → Use 64-digit encryption key
  3. Save the key and make a new backup.
Backups protected only with a password can’t be opened offline — the key is kept on WhatsApp’s servers. Switch to a 64-digit key.

Snapchat data

Read your saved chats and download all Memories from Snapchat’s “My Data” export.

1Your export

The mydata~….zip file(s) from Snapchat’s e-mail, or the unzipped folder.

Nothing chosen

2Save to

Download links expire a few days after Snapchat’s e-mail.

Get your export

  1. Snapchat → Settings → Privacy Controls → My Data
  2. Tick Memories, Chat Media, Chat History, Friends
  3. Turn on Export JSON Files (important)
  4. Submit, then download the zip from the e-mail
Snapchat only exports saved chats. Opened snaps are deleted by Snapchat itself.
